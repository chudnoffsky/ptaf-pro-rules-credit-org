# Репозиторий правил PTAF Pro для кредитных организаций

Набор правил межсетевого экрана уровня веб-приложений PTAF Pro 4.2.2, разработанный для защиты веб-инфраструктуры кредитных организаций.

## О работе

Репозиторий содержит набор из 24 правил и настроек, разработанных в рамках выпускной квалификационной работы по направлению 10.03.01 "Информационная безопасность" (НИУ ВШЭ, МИЭМ, 2026 год). 9 правил являются авторскими и закрывают пробелы в покрытии угроз базовой конфигурацией Default Template PTAF Pro.

**Тема ВКР:** Разработка и внедрение системы мониторинга киберугроз в кредитной организации  
**Автор:** Чудновский Владимир Александрович

## Структура

- `rules/all-rules.md` - код 24 правил в синтаксисе PTAF Pro с обоснованием и привязкой к CVE/CWE
- `rules/rules-code.md` - краткий справочник: только код правил без описаний
- `portability/modsecurity-examples.md` - примеры реализации правил на ModSecurity (демонстрация переносимости)
- `traceability/traceability.md` - таблица соответствия сценариев испытаний (SCN-01 - SCN-32), правил (WAF-01 - WAF-24) и UUID событий безопасности

## Контекст применения

Правила разработаны и верифицированы на лабораторном стенде на официальной платформе TRY PTAF (Positive Technologies) с уязвимым банковским приложением Vulnbank. Правила построены в vendor-independent формате и переносимы на другие WAF-решения (ModSecurity, BI.ZONE WAF, Solar WAF) с трансляцией синтаксиса.

Из 24 правил 20 верифицированы на стенде с фиксацией UUID событий безопасности. Правила WAF-13 и три дополнительных вектора (HTTP Method Override, Request Smuggling, Path Traversal через URI) требуют расширенной конфигурации стенда и проходят валидацию при пилотном развертывании в production-инфраструктуре.

## Метрики эффективности

**Recall = 1,000** (FN = 0) по всем классам угроз - пропусков атак не зафиксировано.  
**Доля ложных срабатываний:** 6,3% на пилотной выборке (2 из 32 сценариев испытаний).

Значение TN (true negative) не определяется журналом PTAF Pro по архитектуре: легитимный трафик не регистрируется в событиях безопасности. Косвенным свидетельством корректной обработки служит успешное выполнение штатных сценариев взаимодействия с приложением Vulnbank без нарушений.

Полная таблица результатов испытаний с UUID событий безопасности приведена в `traceability/traceability.md`.
